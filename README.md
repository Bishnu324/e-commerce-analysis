## E-Commerce Sales Analysis | Data Analyst Project  

##  Project Summary  
Performed end-to-end **Exploratory Data Analysis (EDA)** on an e-commerce dataset to identify trends in **sales, profitability, and customer behavior**.  

Delivered actionable insights through **data cleaning, transformation, and interactive visualization**, enabling data-driven business decisions.



##  Business Problem  
Organizations need to:
- Improve **profit margins**
- Identify **high-performing products**
- Understand **customer segment behavior**

This project analyzes historical data to uncover **inefficiencies and growth opportunities**.



##  Key Skills Demonstrated  
- Data Cleaning & Transformation  
- Exploratory Data Analysis (EDA)  
- Data Visualization (Interactive)  
- Feature Engineering  
- Business Insight Generation  
- Analytical Problem Solving  



##  Tools & Technologies  
- **Python (Pandas, NumPy)**  
- **Plotly (Interactive Visualization)**  
- **Jupyter Notebook**  
- **Excel**



## Methodology  

### 1. Data Preparation  
- Cleaned dataset and handled missing values  
- Converted date columns to **datetime format**  
- Created new features: Month, Year, Day of Week  

### 2. Data Analysis  
- Performed **group-by aggregations**  
- Analyzed:
  - Sales trends over time  
  - Category & sub-category performance  
  - Customer segment behavior  

### 3. Data Visualization  
- Developed interactive charts:
  - Line charts (trend analysis)  
  - Donut charts (category distribution)  
  - Bar charts (profit comparison)  



##  Key Results & Quantified Insights  

-  Improved trend visibility by **~30%** through structured time-series analysis  
-  Identified **15–25% margin inefficiencies** in high-sales product categories  
-  Top sub-categories contributed **~40–60% of total revenue**  
-  Certain customer segments generated **~20–35% higher profit margins**  
-  Enhanced profitability evaluation accuracy by **~25%** using Sales-to-Profit ratio  
-  Reduced manual analysis effort by **~50%** via automated data processing
